2. Positioning and content clarity
The website should feel like a trustworthy, respectful devotional service website—not a generic marketing template.

Clearly distinguish these concepts:
- Maa Baglamukhi / Nalkheda Dham information: temple/dham information, darshan or visit guidance, location and travel details, only where verified.
- Pandit services: puja, havan, anushthan, mantra-jap, or other rituals actually performed by the pandit.
- Kundali / jyotish consultation: list only if the pandit genuinely offers it; explain what a visitor needs to share and how to request a consultation.
- Contact / booking inquiry: the main conversion path for devotees who want to ask about a ritual, date, availability, or required arrangements.
Do not imply that the pandit officially represents or manages the temple unless this has been confirmed. Do not conflate temple administration with an individual pandit's private services. If the website is about a specific pandit, use the verified name consistently. Use a real portrait supplied or approved by the client; do not use a random pandit photo as if it were the actual person.

Adapt this structure to the current routes and project size. Do not create empty or thin pages solely to increase the number of URLs.

8. Frequently asked questions: real practical questions, answered plainly.
9. Contact section: WhatsApp, phone, location/service area, and a short inquiry form if the project supports one.
10. Footer: navigation, contact details, service links, privacy policy if personal data is collected, and appropriate copyright text.
Service detail pages

4. Visual design system
Suggested palette
Use a restrained devotional palette. Apply it consistently and verify contrast in the actual UI.
- Deep maroon: #6F1D2C — primary brand/header emphasis.
- Warm saffron: #C98224 — small accents, icons, dividers; avoid using it for long text.
- Antique gold: #B58A3A — decorative highlights and subtle borders.
- Warm ivory: #FFF9F0 — primary page background.
- White: #FFFFFF — cards and form surfaces.
- Deep charcoal: #292522 — body text.
- Muted text: #6B625C — secondary copy, after contrast check.
- Soft border: #E8DED1 — card and section borders.
Use deep maroon for the primary CTA with white text. Use saffron/gold sparingly so the site feels refined rather than visually noisy. Do not put gold text on ivory or white if the contrast is insufficient. If the current brand already has an approved palette, preserve it where it is working and harmonize rather than changing colors arbitrarily.
Typography
- Use one readable Devanagari-capable font for Hindi and one complementary Latin font if needed. Confirm that all Hindi glyphs render correctly.
- Use clear heading levels and comfortable body line-height.
- Keep paragraphs short; prefer simple Hindi/Hinglish or accessible Hindi based on the existing audience.
- Avoid decorative/script fonts for body copy and small labels.
- Ensure mobile body text is comfortably readable, ideally around 16px or larger.
Components and spacing
- Establish reusable tokens for colors, spacing, radius, shadows, and typography.
- Use consistent card radius, borders, button heights, icon sizing, and hover/focus behavior.
- Prefer subtle borders and restrained shadows over heavy gradients, excessive glow, or multiple competing effects.
- Use Lucide icons if the project already uses them; avoid mixing unrelated icon styles.
- Avoid excessive animations, autoplay media, and parallax that harms usability.
- Do not make every section a card. Alternate simple content sections with focused card groups.

- Keep one primary action label consistent, such as “पूजा के लिए संपर्क करें” or “WhatsApp पर पूछें”. Use labels that accurately describe the next step; do not imply a confirmed booking if it is only an inquiry.

- If there is an inquiry form, include only necessary fields (name, phone/WhatsApp, service, preferred date, optional message), labels, validation, success/error states, and spam protection appropriate to the current backend.
- Do not collect sensitive personal or birth details for kundali unnecessarily. Explain why any required information is needed and how it will be used.
- Never display fake counters, fake urgency, fake reviews, guaranteed results, or misleading “100% solution” claims.
- Respect users who are seeking help with sensitive life problems. Use calm, non-coercive language and never exploit fear or promise that a ritual guarantees legal, medical, financial, relationship, or other outcomes.

Inspect the existing framework and implement its idiomatic SEO approach (for example, Next.js Metadata API if this is a Next.js App Router project). Do not duplicate metadata systems.

For every indexable page:
- Unique, descriptive title that matches the page's actual content.
- Unique meta description written for humans; avoid keyword lists.
- Canonical URL using the final approved domain. Until a production domain is confirmed, do not hard-code an assumed custom domain.
- Appropriate Open Graph title, description, and image; use a real, optimized, approved image.
- Correct robots directives. Keep staging/preview behavior intentional; do not accidentally block the intended production website or index a private preview.
- Add sitemap.xml and robots.txt using the framework's supported method.
- Ensure the site uses one preferred hostname/protocol after the production domain is finalized, with redirects configured at the hosting/domain level if appropriate.
- Set language metadata correctly; if Hindi is the primary language, use hi as appropriate. If there are real Hindi and English versions, implement correct language alternates; do not claim multiple languages without translated pages.
- Use descriptive image alt text when the image conveys information; decorative images should have empty alt text.
- Add breadcrumbs to deeper service pages and connect related pages with useful internal links.
- Ensure one clear H1 per page and logical H2/H3 hierarchy. Do not choose heading levels based only on visual size.
- Avoid duplicate titles, duplicate pages, orphan pages, broken links, and excessive repeated footer keyword text.
Local SEO
- Use the real business/service name, accurate contact information, and a consistent service area.
- Add a clear Contact/Location section. Embed a map only if the location is confirmed and showing it is useful.
